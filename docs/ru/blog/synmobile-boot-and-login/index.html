Arch Linux на Xiaomi 12T Pro: загрузка и вход

Двойная загрузка с Android, заставка прямо на KMS, экран входа и блокировки.

#synmobile

Мой Xiaomi 12T Pro загружает настоящий Arch Linux ARM рядом с Android. Не chroot и не Termux: штатное ядро GKI 5.10 с vendor-модулями самого телефона, systemd и сверху моя Wayland-оболочка synshell. Android остаётся на месте, Arch живёт образом в /data.

Попробовать можно, ничего не прошивая: fastboot boot загружает образ один раз. Для постоянной работы в boot ставится маленькое меню, стоковый образ перед этим сохраняется.
