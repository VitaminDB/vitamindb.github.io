synshell: несколько подключений к интернету сразу

Wi-Fi, кабель и телефон по USB вместе: один основной канал с запасными или все каналы сразу, и свой выбор для каждой программы.

В synshell появилась служба synnetd. С ней Wi-Fi, кабель и телефон по USB работают одновременно, а не сменяют друг друга. Настраивается она в «Параметрах» → «Подключения к интернету».

Два режима

  • «Только основной канал» (по умолчанию): весь трафик идёт через один канал, остальные запасные. Пропал основной — всё переходит на оставшийся. Основной выбирается сам (кабель, затем Wi-Fi, затем USB-модем) или вручную.
  • «Все каналы сразу»: соединения распределяются между каналами, и торренты, обновления и загрузки Steam из многих источников используют их все. Одно соединение всегда идёт через один канал.

Свой выбор для каждой программы

Для каждой программы можно выбрать своё независимо от общего режима: например, торрент-клиент через все каналы, а браузер и звонки — только через Wi-Fi. «Параметры» подсказывают программы, которым это выгоднее всего, — qBittorrent, Transmission, Steam. Внутри процессы программы переносятся в свою cgroup с маленькой BPF-программой, которая ставит метку каждому новому сокету, поэтому канал выбирается уже при connect(), без гонок.

Телефон как USB-модем

Телефон на Android или iPhone в режиме USB-модема служба поднимает сама, своим DHCP-клиентом, — NetworkManager не нужен. Если интерфейс уже настраивает кто-то другой, synnetd его не трогает.

Ничего не ломает

  • Системная таблица маршрутов не меняется: служба держит свои маршруты в отдельных таблицах и правилах. Остановили службу — система работает так, будто её не было.
  • Пока подключён один канал, правил нет совсем; включён VPN — служба не вмешивается.

Как включить

  • sudo systemctl enable --now synnetd — служба входит в пакет synshell-core.
  • Командная строка: synnetd status, synnetd mode primary|both, synnetd primary <интерфейс>|auto, synnetd app <имя> primary|both|system.
  • Подробности — docs/NETD.md в репозитории synshell.
