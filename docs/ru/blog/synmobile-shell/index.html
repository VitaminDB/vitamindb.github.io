На телефоне то же окружение, что на ноутбуке: композитор synwm на smithay и телефонная оболочка synmobile-shell. Композитинг идёт на GPU Adreno 730 через zink поверх Vulkan-драйвера turnip. Всё ниже написано на Rust на моём GUI-фреймворке syngui.
