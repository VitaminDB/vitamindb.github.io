synmobile: Windows games and Android apps

A console-style game mode, Steam, Cuphead through Wine with an on-screen gamepad, and Android apps in a container.

Game mode turns the shell into a console-style launcher: Steam library, Windows games under Wine, Linux games and Android apps in one place, gamepad navigation, every app fullscreen without frames.

Windows games through Wine

Windows games run through wine-arm64ec with DXVK on the turnip Vulkan driver, through Xwayland. Touches become a mouse, and the on-screen controller emulates an Xbox 360 pad.

Android apps

Android runs in a container (LineageOS 20 with Google apps) and its apps open as ordinary windows of the Linux shell.
