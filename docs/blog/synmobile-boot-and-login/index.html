Arch Linux on Xiaomi 12T Pro: boot and login

Dual boot with Android, a boot splash drawn straight to KMS, the login and lock screens.

My Xiaomi 12T Pro boots real Arch Linux ARM next to Android. Not a chroot and not Termux: the stock GKI 5.10 kernel with the phone's own vendor modules, systemd, and my Wayland shell synshell on top. Android stays where it was, and Arch lives in an image file on /data.

You can try it without flashing anything: fastboot boot loads the image once. For everyday use the boot partition gets a small menu; the stock image is backed up first.
