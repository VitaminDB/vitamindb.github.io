synshell on a phone: desktops, widgets, shades

Home pages with live hardware widgets, two pull-down shades, the launcher, recents and a charging animation.

The phone runs the same desktop environment as my laptop: the synwm compositor, built on smithay, and a phone shell, synmobile-shell. Composition runs on the Adreno 730 GPU through zink on top of the turnip Vulkan driver. Everything below is written in Rust on my GUI framework syngui.
