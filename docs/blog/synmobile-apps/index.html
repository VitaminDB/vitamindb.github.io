synmobile: apps and the link to a PC

Settings, file manager, terminal with an on-screen keyboard, resource monitor, maps and the phone's screen on a laptop.

Every app here is a crate of synshell on syngui; the same binaries run on the laptop and adapt to a narrow portrait screen.

synlink links the phone and the PC over USB or Wi-Fi (QUIC with pinned keys): screen and remote input, files, notifications, a shared clipboard and ssh without knowing addresses. All screenshots and videos in this blog were taken through it.
